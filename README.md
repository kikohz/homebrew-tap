# CellGlide Homebrew Tap

[CellGlide](https://cellglide.com/) lets your Mac use your iPhone's cellular connection, over a USB cable or wirelessly.

```bash
brew install --cask kikohz/tap/cellglide
```

CellGlide updates itself; `brew upgrade` isn't needed. `brew uninstall --cask cellglide` gives the network back and removes CellGlide's background helper before removing the app. To also remove its settings and logs, use `brew uninstall --zap --cask cellglide`.

You also need CellGlide for iPhone from the [App Store](https://apps.apple.com/app/id6817531155).
